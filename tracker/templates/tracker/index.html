🔐 Browser Permission Capture — Demo

A mini cybersecurity-awareness project. Each button below triggers a real, native browser permission prompt. Nothing happens silently — your browser always asks first, and the action it performs is shown next to the button. This demonstrates what a website can legitimately access once a user clicks "Allow", and why permission prompts deserve attention.

📷 Camera

Requests camera access and captures a single still frame.

🎤 Microphone

Requests mic access and records a short (3s) audio clip.

📍 Location

Requests geolocation and logs latitude/longitude/accuracy.

Every request, grant, and denial is logged on the backend. View everything captured so far on the dashboard.
